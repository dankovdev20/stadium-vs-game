# Stadium VS — Backend Engine

Серверная часть многопользовательской интерактивной игры 1v1 (Резервирование комнат, Kiosk WebSocket, FSM стейт-машина, расчет пенальти по вероятностям).

## Запуск проекта

1. Установка зависимостей:
\`\`\`bash
npm install
\`\`\`

2. Запуск автотестов (правила из PDF, барьерная синхронизация, Монте-Карло 10k):
\`\`\`bash
npm test
\`\`\`

3. Запуск игрового сервера:
\`\`\`bash
npm start
\`\`\`
Сервер доступен по адресу: \`http://localhost:3000\` (или по локальному IP в LAN).

## Архитектура и контракты
Полный реестр событий WebSocket, FSM-машина и контракты для фронтенда зафиксированы в файле **\`put_me_in_context.md\`**.
